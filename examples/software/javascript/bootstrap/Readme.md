This folder contains the computation code for building the popular JavaScript library `bootstrap` using the (documentation for its build process)[https://getbootstrap.com/docs/5.3/getting-started/contribute/].

It uses the (bootstrap v5.3.8)[https://github.com/twbs/bootstrap/archive/v5.3.8.zip] with SHA-256 hash value: 4f36c463a1079debab6b5e43e09e14253d3aa896939967b3e9f9098edc39e448 while building the container image.

During its run, it produces the `dist/` contents and copies them to the output for certification.
