This folder contains the computation code for minimizing the popular JavaScript library `jQuery-3.7.1.js` using (Terser)[https://terser.org/], a popular JavaScript mangler and compressor toolkit.

It produces the `jQuery-3.7.1.min.js` and `jQuery-3.7.1.min.js.map` files.
