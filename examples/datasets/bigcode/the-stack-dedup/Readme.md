This folder contains property computation code for the [HuggingFace bigcode/the-stack-dedup](https://huggingface.co/datasets/bigcode/the-stack-dedup) dataset.

## Properties extracted:
- Per dataset file (e.g., `c/data-00000-of-*.parquet`):
    - For each column:
        - missing
        - types
    - A "licenses" property based on the column "max_stars_repo_licenses":
        - unique_licenses: a list of all licenses that appear in the dataset
        - count_per_license: how many projects per license
        (The column "none" means no license was detected. This should be 0.)
        - multiple_licenses: the number of entries with multiple licenses
    - A "natural_languages" property that determines the natural languages used
      in comments.

## Note
- Too big (996GB) for `hf_cache` method of uploading
- `hf_config_filter.txt` works only for `hf_url`, not for `hf_cache`
- Requires `hf_token` for `hf_url`, which is not supported/implemented in the server (`dev_test_docker/test_docker.py` works)

As a result, when there is a `token_path` in `hf_url` input, it is downloaded first and uploaded as `direct` upload rather than `url`.
