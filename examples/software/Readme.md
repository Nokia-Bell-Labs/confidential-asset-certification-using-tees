This folder contains various proof-of-concept examples when dealing with confidential software assets.

- [javascript/bootstrap/](javascript/bootstrap/): Minimize and package Bootstrap 5.3.8
- [ros-realtime/](ros-realtime/): Build RT_PREEMPT kernel packages for Raspberry Pi for real-time ROS
- [sbom/](sbom/): Generate SBOM with syft, scan vulnerabilities with grype and trivy, check licenses with trivy for container images (e.g., nvidia, ubuntu, python)
