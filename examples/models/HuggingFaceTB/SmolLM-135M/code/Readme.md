This folder contains the property computation code for the [HuggingFace HuggingFaceTB/SmolLM-135M](https://huggingface.co/HuggingFaceTB/SmolLM-135M) model on the [GPQA](https://huggingface.co/datasets/Idavidrein/gpqa) benchmark.

The folder structure is as follows:
- `cpu`: the property computation code that can run on CPU
- `gpu`: the property computation code that can run on a GPU
